## وصفات جاهزة (اتجربت)
- **نصين (نضيف + جلو):** Source Text الجلو = إكسبريشن من الأساسي (setText/setFont/setFontSize)، لونه من Color Control.
- **لون نص من غير إكسبريشن على خاصية معروضة:** Add Animator > Fill Color (Range 0–100 بيغطي الكل) وحرّكه لأول الستاك (`moveTo(1)`)، واعرض/اربط Fill Color.
- **Deep Glow:** Radius/Exposure كنسبة من سلايدر؛ مدى السلايدر 0–300.
- **عدّاد أرقام:** Slider `Target Number` + `value / M * T` على Animate Value، مدى لحد 100000.
- **شكل بيتظبط على النص (هايلايتر/فريم/خط):** `sourceRectAtTime(I_, false)` على ليير النص + `toComp` للركنين. القياس في وقت ثابت (نهاية الدخول) عشان الأنيميتورز ما تهزّش الصندوق.
- **خط بسُمك وطول منفصلين:** Scale X من العرض المطلوب، Scale Y = Thickness% (الخط أفقي).
- **لون شكل جريدينت:** Hue/Saturation Colorize (rgbToHsl). ما تستخدمش Fill/Tint.

## مشاكل تقنية معروفة
- **ExtendScript:**
  - **الـternary المتداخل من غير أقواس بيتقرا غلط** (`a ? x : b ? y : z`) — حط أقواس دايمًا.
  - `ly instanceof TextLayer` أضمن من `!!ly.property(...)`.
  - مفيش JSON → `eval("(" + txt + ")")`.
  - `File.name` بالعربي URL-encoded → `decodeURI`.
  - ما تسمّيش متغير بنفس اسم دالة؛ try/catch لكل خاصية؛ ما تعرّفش function جوه loop.
- **الإكسبريشنز:**
  - **ليير 2D: Scale و Position في الإكسبريشن طولهم 2** (رغم إن ExtendScript بيرجّع 3) → `v[2]` = undefined = "Undefined value used". اكتب: `v.length > 2 ? [..,..,v[2]] : [..,..]`.
  - خاصية مخفية → `canSetExpression` false/`set expression` error → اتخطاها بـtry.
  - الإكسبريشن بيتقيّم lazy؛ عشان تعرف الأخطاء: `prop.valueAtTime(t,false)` وبعدين `expressionError`.
  - setValueAtTime على Time Remap بعد ما تمسح كل الكيز → error "property hidden". (ومع ذلك: ما تستخدمش time remap للهولد.)
- **التصدير:** `exportAsMotionGraphicsTemplate(true, folder)` بياخد فولدر. صدّر بالـitemByID بعد الحفظ. `app.beginSuppressDialogs()` وإلا الدايالوجز توقف.
- **نقل الملفات (مهم):** `device_commit_files` لنفس المسار **ساعات بيكتب نسخة قديمة** (اتكرر 3 مرات وشغّل سكربت قديم). **بعد كل commit اعمل `device_list_dir` وقارن الحجم بـ`wc -c`**؛ لو مختلف ابعت باسم جديد (`_v2`). نفس الشيء لملفات الموجرت: commit لفولدر جديد (`templates\v4`).
- **Run Script File:** File > Scripts > Run Script File → خانة File name → Ctrl+A → Ctrl+V بالمسار → Enter (خد سكرين شوت الأول، الأماكن بتتغير مع الشاشة). الـalert بيظهر في نص الشاشة → اقفله قبل اللي بعده. الـbatch يبقى انتظاره ≤ 50ث (الـbridge بيقطع عند 60).
- **AE UI:** نافذة Claude بتغطي فوق يمين؛ بانل EGP لما يتكبّر الإحداثيات بتتغير (Add Formatting تحت شمال (58,777)، Add Group (22,765)، Add Comment (25,753)). سحب غلط ممكن يرسي تاب كومب جوه فريم EGP → اقفله من الـx بتاعه.
- **بريمير:** Install Motion Graphics Template من Graphics and Titles. السحب من Graphics Templates للتايملاين من بعيد مااشتغلش (والنافذة بتغطي البانل) → عبدالله يجرّب بنفسه.
- `saveFrameToPng(t, file)` بيصوّر فريم من الكومب (للسناب) — أسرع من الريندر.
- **الحافظة:** الكتابة العربي بـ`computer_type` بتستخدم الحافظة؛ من غير clipboardWrite بيلصق القديم (حصل: النص بقى @abdallah.film). استخدم `computer_write_clipboard` + Ctrl+V.
- الـcommit لازم من `/mnt/user-data/outputs/`. افحص أي jsx بـ `node -e "new Function(...)"` قبل ما تبعته (تعليق `//` قفّل `}` مرة)، و py بـ `py_compile`.
- بعد التصدير ما تلمسش AE objects في نفس السكربت (اكتب التقرير قبله). ما تفتحش Undo group جوه حاجة فاتحة واحد.
- File Explorer مسموح كليك بس → افتح الملفات من حوار Open جوه AE. حوار Run Script File: الأضمن خانة File name + المسار الكامل.
- إضافة Guava القديمة (`%AppData%\Adobe\CEP\extensions\com.abdallahfilm.mogrtguava`) مرجع أفكار؛ لو بانلها مفتوح بيوسّخ المشروع → يتقفل.
- صلاحية التحكم بتنتهي بعد 30 دقيقة → resolve + request تاني. **آخر الشغل: `computer_release_lock`.**

## قواعد ذكية (اتعلمناها)
- **كل موجرت: دخول + هولد + خروج.** دخول بس → خروج معكوس (T_ أو Time-Reverse).
- **نقطة الهولد = آخر فريم الدخول الكامل** مش آخر الكومب (آخر الكومب ممكن يكون فيه خروج النص → حروف غامقة). الافتراضي 0.9ث مع ضغط الـdelay بتاع الحروف.
- **الكومب الأصلي قصير (0.7–2.5ث، مقطع من ريل)** → الماستر = intro 0.9 + hold 2.5 + outro 0.9.
- **ليير برا الـoutPoint بيختفي** → مدّ outPoint كل الليرز لآخر الماستر.
- **الألوان الأحمر [1,0,0] في النص/الجلو = Accent؛ برتقاني Deep Glow outer = Glow Color؛ الأبيض في ستروك الأشكال يفضل أبيض.**
- **ما تحطش إكسبريشن على خاصية معروضة في EGP** إلا بـ`value` (زي Scale الخط) — الأحسن تعرض سلايدر في Controls.
- **العربي:** Ligatures لكل طبقة فيها 0600–06FF. الكشيدة في الافتراضي (`عبـــدالله`).
- **التمرير بالماوس فوق سلايدر بيغيّر قيمته.**
- **القيم الافتراضية = اللي في الكنترولز وقت التصدير.**
- **تمبلت عبدالله الجاهز:** متعدلش التصميم، صحّح الأسماء بس.
- **Fill effect على لير شيب بيغطي ألوان الشيب** — لو عرضت لون الشيب اربطه بالـFill أو اعرض لون الـFill.
- **التوقيت جوه البريكومبات:** وقت الكيفريم عبر `startTime` و`stretch` (m = a + b·t). Time remap يتعلّم ومتتحسبش.
- **المقدمة/النهاية في الدفعة:** أكبر فجوة بين الكيفريمز = الهولد. تجاهل loopOut/loopIn والكيز بعد النهاية. السالبة من 0. الحماية في الماستر وكل بريكومب. لو عبدالله عامل حماية بإيده (Up Text) → export_only بس.
- **كومب طويل جدًا** (62ث): قص لآخر outPoint الأول. **وقت فاضي في الآخر** > ثانية بعد الخروج → قصّ لآخر كي + فريم.
- **إكسبريشنز inPoint/time** (Trim In، Flicker، overshoot) جوه المقدمة → المقدمة لازم تغطيها؛ Trim In مابيتعكسش بـguava_add_outro (البيلد الذكي بيعكسه بـT_).
- **TextEvo/animator expressions:** الكيفريمز على Strength/Start بتحدد الدخول والخروج.
- **بعد addProperty أي reference قديمة بتبقى invalid** → هات الخاصية تاني.
- **رأي عبدالله:** الحركة في الهولد (سويب هادي، روتيشن بطيء) مطلوبة بس بشكل خفيف؛ الشكل لازم يتحكم فيه "براحتنا" (offset + scale لكل عنصر)؛ الجمالية الأصلية أهم من التحكم.

## السرعة (قواعد توفير)
- خطة واحدة: inspect → jobs.json → build → snap → جروبات → (تصدير بأمر). ما تعملش 10 نسخ من السكربت؛ صلّح في نفس الملف وابعته باسم جديد بس لو الـcommit علّق.
- batch لكل سلسلة متوقعة؛ زوم بدل سكرين كامل؛ scale 0.5–0.6.
- ما تسألش عن اختيار الكنترولز — الجدول القياسي، وقول في الآخر.
