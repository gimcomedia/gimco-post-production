## 31) الكومب وخلفيات إضافية (بالإفكتات الأساسية بس)
**إعداد الكومب:** 4K UHD (3840×2160)، و**60 fps** (اتقال شفاهة «لأن أغلب فيديوهات الـ SaaS الحلوة 60»، تقريبي). **تضارب مع باقي الوصفة (1920×1080 @30):** 4K/60 لما الهدف عرض ناعم على شاشة أو موقع والجهاز يستحمل (الريندر أبطأ)؛ لريل عمودي 1080×1920 اختار 30 أو 60 حسب التسليم. ابدأ بسوليد وبعدين الإفكت. **سيب مركز الكادر فاضي** للنص والـ UI (الشيء الأسطع بعيد عن مكانهم).

1. **Radial Ramp بسيط:** Solid ← Effect > Generate > **Gradient Ramp**، Ramp Shape **Radial Ramp**، Start Color أبيض / End Color أسود، Start of Ramp **1920,0** و End of Ramp **1920,2160** (على 4K)، وحرّك المقبضين لنقطتي الأبيض والأسود. لوّن واحد بوردي فاتح جدًا. Blend With Original 0%.
2. **4-Color Gradient بإزاحة:** Solid ← Generate > **4-Color Gradient**. اللون الأربعة نفس الدرجة (وردي غامق) وواحد أفتح، وارفع **Blend** لحد ما النقط تندمج. كيفريم لكل Color Point في أوقات مختلفة بسحب صغير عشان الخلفية ما تبقاش ميتة. للّوب: على Point 1 `loopOut("pingpong")`:
   ```
   loopOut("pingpong")
   ```
   (مقروء). مواضع نقط مقروءة على الشاشة (4K): Point 2 **2268, 1852** · Point 3 **844, 1820** · Point 4 **3576, 452** · Point 1 حوالي **4808, 252** (جزئي).
3. **خلفية شبكة (تقنية/بيانات):** Solid أسود (Fill)، فوقه شيب بفيل أصفر غامق، عليه **Turbulent Displace**: Type Turbulent، Amount **194**، Size **486**، Offset **1920,1080**، Complexity **1.0**، Pinning Pin All. Evolution بإكسبريشن (المسموع غالبًا `time*100`، غير مؤكد). **Fast Box Blur** على الشيب (المسموع 800–1000، **تقريبي**، مش مقروء). فوق كله **Adjustment Layer** + Effect > Generate > **Grid**: Anchor في النص، Size From = Width & Height Sliders، **Width 32** و**Height 32** وعلى Height إكسبريشن:
   ```
   effect("Grid")("Width")
   ```
   Border **5**، Color أبيض، Opacity 100، Blending Mode **Screen**. اختار الـ Blend Mode بالعين (Shift+ و Shift− على اللاير بيبدّل). كيفريم **Anchor** الجريد من تحت لفوق عشان يتحرك.
4. **خلفية Displacement Map:** Solid أسود، شيب بأبيض وأسود (Colorize) بحزمة بيضا وحزمة سودا، كرّره كذا مرة واعمله **Pre-compose** اسمه «map» وخبّيه. **Adjustment Layer** فوق السوليد + Effect > Distort > **Displacement Map**: Map Layer = «map»، Use For Horizontal **Red**، Vertical **Green**، Behavior **Center Map**، Expand Output On، Wrap Pixels Around Off. Max Horizontal حوالي **50**، Max Vertical **0** (القيمة على الشاشة كانت 5، **مش متأكدة**). حط شيب أخضر مرجعي تحته وبلّره عشان تشوف الإزاحة وامسحه بعدين. Fast Box Blur فوق للنعومة.
5. **Radial Ramp + نجمة Poly Star + Wave Warp (الأعقد):** Solid بـ Radial Ramp وردي وبلور خفيف. شيب **Poly Star** في النص، ارفع Inner Radius عشان ما تبقاش رفيعة، Gradient Fill غامق لفاتح. إفكتات الشيب بالترتيب (مقروء): **Fast Box Blur** Radius **115**، Iterations 3، Repeat Edge Pixels On ← **Wave Warp** (Wave Type **Uncircle**، Height **290**، Width **500**، Direction **0x+140°**، Wave Speed **1.0** ثم **0.2**، Pinning None، Antialiasing Low) ← Wave Warp 2 بنفس القيم وSpeed **0.2** ← **Fast Box Blur 2** Radius **22**، Iterations 3. (المنطوق «sine» للتاني، والشاشة قالت Uncircle.)
- **قرار:** الخلفية حسب البريف: جريديانت نضيف للنص، شبكة للتقني/بيانات، Displacement وWave Warp للإيقاع العالي. **حركة بطيئة**: Wave Speed 0.2 مش 1.0 (1.0 سريع على العين). استخدم Adjustment Layer للنسيج المشترك (جريد، بلور) وPre-comp للأجزاء المتكررة (map، النجمة).
- **ملاحظة:** Wave Warp في 5.3 (عمودي، Speed 0.1) نسخة تانية: دي قيم أنعم وأفقية بزاوية 140°.
- **على ذوقنا:** الأقرب هو 1 و2 ولون واحد درجات؛ الشبكة بخط رفيع وبلور عالي؛ ماتبقاش نجمة ملونة كبيرة في نص الكادر لو فيه عنوان.
- **عربي:** مفيش نص هنا. حط العنوان العربي في الثلث العلوي أو السفلي حيث الجريديانت هادي.
