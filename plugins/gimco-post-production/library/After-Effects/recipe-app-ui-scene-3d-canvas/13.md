## 13) مشاكل وحلول
| المشكلة | الحل |
|---|---|
| اللايرات اختفت بعد سويتش الـ 3D، أو الجريديانت ما ظهرش على الشيب | الريندرر: Classic 3D (القسم 3) |
| لاير نط من مكانه لما اتحول 3D بعد الربط أو التحريك | 3D الأول. لو حصل والـ Position عليه كيفريمات: رجّعه بالـ Anchor Point، وراجع الماتّ، وبعدين اربطه بالـ Null |
| بري-كومب (جلو + عنصر) مش ماشي مع الكاميرا أو مكانه غلط | البري-كومب نفسه يتحول 3D، ويتراجع مكانه |
| نص 3D جديد ظهر فوق عند مكان الكاميرا الأصلي | نزّل Position للمنطقة اللي شغال فيها |
| العنصر المتحرك بيتقاطع مع لايرات تانية | فوق كل اللايرات في الستاك، و Fade أسرع للّي بيسد |
| إفكت Transform ما بانش على لاير 3D | Position و Opacity بتوع اللاير (القسم 5) |
| كل حاجة داخلة مع بعض | ستاجر: زحلق الـ in-points |
| الحركة مستعجلة | ابدأ بدري وخلّيها أبطأ |
| النطّة تقيلة، أو العنصر جاي من بعيد | قصّر المسافة؛ العنصر الكبير حركته أقل |
| العنصر باين قبل دخوله | أول كي Opacity 0% بالظبط |
| نص الزرار فضل ظاهر والزرار داخل | الـ Parent ما بيورّثش Opacity: كيفريم على النص |
| لصق كيفريمات Position نقل العنصر فوق أخوه | رجّعه بالـ Anchor Point |
| أركان الكارت اتمطّت لما طوّلته | شيب جديد بالمقاس، مش Scale |
| حركة Position و Scale مع بعض مفككة | قمة سرعة الاتنين في نفس اللحظة |
| جلو الكيرسر أو الأيقونة مقصوص | Adjustment Layer + Pre-compose |
| الجلو كشف حدود الكارت المستطيلة | قلّل Radius و Exposure |
| الـ Pre-compose فك ربط العنصر بأبوه | اربط البري-كومب بنفس الأب |
| بلور الدخول قاطع عند حواف الكارت | Repeat Edge Pixels مقفول على بلور الدخول |
| أركان الكروت بتبوظ وقت الدخول | Roughen Edges آخر إفكت |
| حافة الخلفية الجديدة حادة حتى مع البلور | Linear Wipe بـ Feather عالي، مش تحريك الـ Solid |
| الخلفية الجديدة مش مغطية الكادر في الآخر | راجع قيمة النهاية مع الـ Feather العالي |
| الفينيت رمّد مشهد أبيض | Angle of View واطي و Amount أقل |
| الكيرسر راجع من مسار شكله معكوس | Time-Reverse Keyframes بعد اللصق |
| الـ Guides مش في مكانها بعد النزول في الكانفاس | Guides جديدة للمنطقة |
