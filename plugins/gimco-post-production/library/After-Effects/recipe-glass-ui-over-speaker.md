## وصفة: ستايل "Glass UI + Green Screen" (مشروع مشروع ستايل عميل، AE 2026، 1080x1920 @25fps، ~54s)
ريل توكينج هيد عن البراندنج، المتكلم متصور جرين سكرين ومركّب على غرفة مولّدة، وفوقه عناصر UI زجاجية متوهجة بتشرح الكلام.

> **حارس طبي:** لو الريل طبي، قواعد [medical](../Specialized/medical.md) تكسب: Teal مطفي مش نيون، وأي «قبل/بعد» بموافقة مكتوبة ومن غير ادّعاء نتيجة.

### الهيكل
- Main: 3 بري-كومبات Hook (0-8.5s) / Body / End + أدجستمنت لايرز فوقهم.
- Hook وBody: كل حاجة متربوطة بـ Null (Parent) عشان Punch-in/حركة كاميرا موحدة (Null 1: Scale ~131% مع كيفريمات).
- Body: كومب 3D فيه Camera 1 مربوطة بـ Null 2 جوه Null 2 (ريج كاميرا)، والـ Position بتاع النل متكيفرم كل 1.5-3 ثواني = دفعة/انجراف كاميرا مع كل جملة.

### المتكلم (Green Screen)
- Keylight 1.2 (Screen Colour أخضر، Gain 100، Balance 50) -> Lumetri Color -> CC Light Sweep 3 (Direction +33°, Width 210, Edge Intensity 159, Edge Thickness متكيفرمة) = ريم لايت على الحواف.
- الخلفية: ROOM 2.png (غرفة ديكور ببراويز وإضاءة دافية) + BG.png.
- نسخ إضافية من نفس الفيديو المكيّد بـ Blend Add في لحظات معينة لتقوية الريم/التوهج.
- Shape Layers ورا المتكلم عليها Deep Glow ضخم (Radius ~972, Exposure 0.65) = إضاءات/لايت ليكس خلفية.
- Mask: Fill أسود Opacity 80% لتغميق الأطراف/التحت.

### عناصر الـ UI الزجاجية
- بيلز/أزرار مستديرة (1 2 3، Reference، Brand Identity، competitors، Client مع علامة صح، Qyala Editor) = Shape Layers (Rounded Rect بستروك فاتح) + نص، كل لاير عليه Animation Composer In preset (AC IN [YRH]).
- على البري-كومب: Deep Glow (Radius 250, Exposure ~0.49) + Shadow Studio 3 (Directional, Raytraced, Light Direction 135°, Softness 64-78%, Shadow Length 200, Opacity Start 23% -> End 0%) = عمق وظل ناعم.
- جنب البيل: خطين عموديين (II) زي أيقونة Pause، ونص صغير برتقالي تحت الكلمة (مثلا Brand + Identity).

### النصوص العربي
- كلمة رئيسية بيضاء بولد + سطر برتقالي/أصفر أصغر تحتها، ونقاط برتقالي جنب البنود (الألوان • العناصر).
- إنيميشن: TextEvo (Strength متكيفرم، Delay 7.6، Reading direction) أو بريست "TR In" من ماركرز، + AC IN Gaussian Blur (Legacy).
- Deep Glow (Radius 250, Exposure 0.22-0.5) + CC Light Sweep على النص (Direction -30°, Sharp, Width 50, Sweep Intensity 25, Edge 50, Thickness 4, Light Reception Add) بالـ Center متحرك = لمعة تعدّي على الكلام.
- نص الهوك الختامي برتقالي متوهج (بينسوا آخر سؤال).

### أفكار بصرية بتشرح الكلام
- جمهور/عملاء: سيلويت ناس أبيض متوهج (بري-كومب man مكرر 6 مرات) عليه Gaussian Blur 14 + AC IN Bounce + CC Scatterize (Scatter متكيفرم: الناس تتجمع ثم تتبعثر) + Fill أحمر في النهاية = جزيئات حمرا متناثرة.
- صف دوائر/فيسز متوهجة (audience/Faces) بيظهر منها وش العميل في دايرة.
- لقطات شاشة: شات واتساب حقيقي (Whats app BG + Chat) وشبكة كروت ستايلات (Collage / Minimal / 3D / Documentary / Storytelling / UI).
- وش مقرّب في دايرة بنضارة UI.
- أيقونة شبكة مربعات برتقالي (# متوهج) فوق الجملة.

### الترانزيشنز والفينش
- بين الأقسام: Adjustment Layer بـ Blend Add وOpacity 0 -> 84% -> 0 (فلاش أبيض ~4 فريمات) + Adjustment Layer عليه Deep Glow متكيفرم (Radius 0 -> 250 -> 0، Exposure 0 -> 0.69 -> 0 على فريمات 8:11 / 8:14 / 8:18).
- جوه الهوك: BCC Ripple Dissolve على أدجستمنت (Radius Peak 500, Wave Width 50, Inside Radius 400, Light Level 349) = موجة كشف.
- فوق كل الفيديو: CC Vignette (Amount 8) + Radial Blur Spin (Amount 2، Center 580/652) = تنعيم أطراف خفيف. وعلى سيلويت الجمهور Radial Blur Spin 5.

### بلجنز مستخدمة
Deep Glow، TextEvo، Shadow Studio 3، Animation Composer (AC IN)، BCC Ripple Dissolve، Keylight، CC Light Sweep، CC Scatterize.

## وصفة: عوالم بتتبدل ورا متكلم كروما + كشف الأخضر (ريل خدمة تصوير كروما، 9:16)
المتكلم في لقطة واحدة متصلة على جرين سكرين، واللي بيتغير هو العالم وراه بس، على الكلمة اللي بتتقال.

### الهوك: مكان لكل كلمة ثم كشف الخدعة
- كل كلمة مكان ("بمكتب"، "مطعم"، "بنص المدينة") = كت حاد للخلفية على أول مقطع من الكلمة، والمتكلم والكابشن ثابتين في مكانهم (هم خيط الاستمرارية).
- الضربة: على جملة زي "إحنا ما اتحركنا من مكانا" الخلفية تختفي ويبان **الأخضر الخام** والكلمة الضخمة فوقه، وكبسولة "مع تصوير الكروما". كشف الخدعة نفسه هو الإثبات.
- بعدها يرجع لـ **العالم الأساسي** بتاع البراند (ستوديو بلون البراند، أشعة ضوء Volumetric مايلة، وعنصر ديكور ثقافي زي خط عربي في ركن فوق) ويفضل هو البيت اللي الفيديو بيرجعله بين الخرجات.

### ليستة أنواع = عالم لكل بند
- كل نوع محتوى (تعريفي، إعلان، بودكاست، شرح خدمة) ليه ست يناسبه (صالون هادي، ستوديو منوّر، ست بودكاست بمايكات...)، والكلمة جوه دايرة جلاس على جنب تحت. المعنى: "كل فيديو بعالم مختلف".

### الدمج عشان يبان حقيقي
- اتجاه ولون الإضاءة على المتكلم يتظبط لكل خلفية (Lumetri/Curves لكل عالم، ولمسة ريم من ناحية مصدر النور).
- ظل تلامس تحت الرجلين (Ellipse أسود متغبّش Multiply) + Blur خفيف على الخلفية للعمق.
- الخلفيات مولّدة بنفس زاوية الكاميرا وارتفاعها ومكان الأرضية، والمتكلم ماشي على نفس خط الأرض.

### عناصر الجلاس (نفس العيلة طول الفيديو)
- قوس جلاس طالع من تحت على جسم المتكلم كفرشة للكابشن ذو المستويين: سطر صغير أبيض خفيف + كلمة ضخمة ذهبي/برتقالي بكشيدة و Glow.
- دايرة جلاس فيها أيقونة Line ذهبي متوهجة (لمبة = فكرة، شريط فيلم بمقص = مونتاج)، أو فيها كلمة.
- كبسولة جلاس للجملة المفتاحية ("لا تدور المكان").
- لوح جلاس كبير بيعدّي في الكادر كـ Wipe، والكابشن الجاي بيظهر وراه.

## عرض الشغل كشوريل (Before / After / Timeline)
لبوستات البورتفوليو: خلفية جريديانت بلون البراند، وتلات لوحات متزامنة: الخام (الأخضر) صغير على الشمال، النتيجة النهائية أكبر في النص، وتايملاين البريمير تحت ماشي مع البلاي هيد. بيبيع المهارة لأن الفرق بين الخام والنهائي باين في نفس اللحظة.
