## 6) مشاكل وحلول
| المشكلة | الحل |
|---|---|
| القطاع بيسيب مكانه وهو بيلف | Anchor أو Position اتلمسوا: رجّعهم (0,0 و 540,960) ولفّ بس |
| طرف الفاصل بيسيب الدايرة | الخط مش في المركز بالظبط: Position 540,960 |
| قوس القطاع أعوج | هاندلز الـ Convert Vertex تتسحب أفقي بس |
| العجلة بتدور حوالين نقطة بدل ما تلف | Anchor الـ Null في النص |
| العجلة لفّت لفّة زيادة | خانة اللفات 0x مش ‎−1x |
| الخلفية اتغمّقت واتبلورت مع القطاعات | Pre-compose للقطاعات المطفية مع لاير التغميق |
| البري-كومب ما بيلفّش مع العجلة | اربطه بـ Null القسم عند أول فريم |
| القطاع الغلط هو اللي منوّر | لاير التغميق لازم يبقى تحت مجموعة النشط على طول، وبيتنقل مع كل قسم |
| ظل الرقم لسه بالرقم القديم | غيّر نسخة الظل كمان |
| الألوان فاقعة على باكدروب | غمّق، وقوّي الظل الجوّاني تاني بعد الجلو |
| اللوك ضاع لما الصورة اتبدّلت | الإفكتات على نسخ الـ Placeholder مش على الصورة |
| الماتّ اتحرك والصورة واقفة | الصورة كمان Parent للـ Null |
| شيب أبيض ظاهر فوق الكارت | الـ Placeholder (مصدر الماتّ) لازم يفضل مخفي |
| الكارت بيظهر قبل ما ينط | كيفريمات Opacity اتزحلقت من غير Scale: رجّعهم مع بعض |
| الكارت المختار بيتغطّى وهو بيكبر | لايراته فوق الستاك |
| الواجهة اختفت لما اتحولت 3D | ورا الموديل: قدّمها في Z من Custom View وصلّح الـ Scale |
| الكارت المنوّر اتحرق أبيض | سبوت قوي فوق جلو: شيله، أو من غير لايتات |
| الكاميرا شكلها روبوت | قرّب نقطة البداية |
| Preview بطيء | Quarter، وسيب الكاش يتبني |
