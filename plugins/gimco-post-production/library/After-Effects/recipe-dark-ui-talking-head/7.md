## 7) النقلات بين المتكلم والجرافيك
القطع بيستخبى جوه فلاش أو زوم أو تحوّل. المقاس:

| النقلة | المدة |
|---|---|
| العنصر نفسه بيكبر ويملا الكادر (كارت أو بار، ببلور أبيض) | 12–18 فريم |
| كت حاد على الـ UI | 0 |
| فلاش أبيض أو رمادي بيهدى (اللقطة بتتغير تحته، والنص موجود من أوله) | 15–18 فريم |
| تسريب نور وردي وأبيض | حوالي 6 |
| ضباب أبيض (Fog dissolve) | 6–9 |
| جليتش شرايح أفقية بفصل RGB | 4–10 |
| Whip أو Zoom blur | 3–6 |
| كادر المتكلم بيصغر لكارت أو أيقونة | 4–9 |
| الواجهة بتبعد وتطلع موبايل في إيد | حوالي 18 |
| Blur dissolve رجوعًا للمتكلم | 4–6 |
| تغميق المتكلم تحت جهاز 3D | حوالي 3 |
| حركة كاميرا جوه الواجهة (Pan أو Tilt أو Zoom للعنصر الجاي بموشن بلور) | مستمرة |

- إمتى ترانزيشن أصلًا: [framing-and-cut-transitions](../../Visual-Direction/framing-and-cut-transitions.md). واللي يتاخد من الجدول ده عندنا في القسم 11.
