## 12) مشاكل وحلول
| المشكلة | الحل |
|---|---|
| الكابشن طالع طويل من بريمير | نزّل Maximum length لآخره، وبعدها Lines: Single |
| كابشنز الهوك بتبدأ قبل كليبها | قص كل بلوك على كليبه قبل النقل |
| Un-PreCompose طلّع خطأ | كرره. واتأكد إنه من منيو Layer، مش كليك يمين > Pre-compose |
| لايرات النص وصلت صغيرة والأنكور على الطرف والمكان في نص الكادر | Ctrl+Alt+Home، Scale 120%، ونزّلها على الـ Guides |
| القطارة على نص الريفرنس جابت رمادي غامق | فتّحه: النص الأساسي حوالي `#ECECEC` |
| الظل نفسه منوّر | الجلو جه بعد الظل: رجّع Radial Shadow آخر الستاك |
| الجريديانت أو اللمعة مش راكبين على الكلمة بعد اللصق | نقط الـ Gradient Ramp ومركز وزاوية الـ CC Light Sweep ثابتين على اللاير: ظبّطهم على الكلمة الجديدة |
| Deep Glow بالديفولت حرق الكلمة | Exposure 1.0 كتير: 0.10–0.20 |
| كلمتين في سطر بيتقروا كلمة واحدة، أو السطر مش متسنتر | وسّع المسافة، وحدد لايرات السطر مع بعض وسنترهم كمجموعة |
| Shatter بيوري سلك أو طوب | View: Rendered، و Pattern: Glass |
| Shatter كسّر الكليب وكل اللي تحته | Pre-compose للـ Adjustment Layer مع لايرات النص بس |
| التكسير بدأ من نصه، أو قبل ما الكلمة تتقري | ما تقصّش أول اللاير: زحلقه لقدام |
| القطع بتقع لتحت | Gravity 0 (أو 1 بالكتير) و Viscosity أعلى |
| الجلو بيتكسر مع النص | الجلو بعد Shatter: على البري-كومب، أو على الـ Adjustment Layer بعد الإفكت |
| التكسير طالع من نص الكومب مش من مكان الضربة | Origin و Force 1 Position على نقطة الضربة |
| جلو أو بلور الأيقونة مقصوص مربع | Adjustment Layer + Pre-compose، أو الإفكت على البري-كومب من برا |
| CC Radial Fast Blur شوّه الأيقونة | سيب نسخة نضيفة فوق النسخة المبلورة |
| مفيش Motion Blur على الأيقونة | السويتش على لاير البري-كومب، وجواه، وسويتش الكومب |
| دايرة التوجل بتكبر أو تتحرك من ركن | Anchor في النص قبل الـ Scale |
| الأبناء فضلوا ظاهرين بعد Fade الماستر | الـ Parent ما بيورّثش Opacity: كيفريم على كل لاير |
| الستاجر حرّك الماستر وساب كيفريمات الأبناء | اظهر لايرات الـ Shy قبل ما تحرّك التوقيت |
| الجلو على لاير الملي مقصوص بالماتّ | Pre-compose للّاير والماتّ، والجلو على البري-كومب |
| الإطار بيتمدد ناحية ركن | Anchor في النص |
| الستروك تخن بعد الجلو | Stroke 2 |
| ليبل الـ UI طالع كابيتال | سويتش All Caps متورّث: اقفله |
| أيقونة PNG ما ظهرتش بعد الاستيراد | نزّلها واستوردها تاني |
| افتر بيهنّج | اقفل بريمير والبانلات الزيادة |
| حكم على التوقيت من غير رندر | Preview كامل الأول، و Full قبل الحكم على الجلو |

**عادات بتسرّع:**
- ستاك النص بيتنسخ من كلمة خلصت: اقفل الإفكتات، حددها كلها، Ctrl+C، وعلى اللاير الجديد امسح إفكتاته و Ctrl+V، وظبّط النقط.
- هوك جديد = Duplicate لقسم الهوك اللي قبله في نفس الكومب، والكلمة الخاصة Duplicate من هوك سابق بلون جديد، ولايرين البوست منسوخين.
- التصميم الأول (الشكل ثابت ومظبوط)، وبعده التحريك.
- بعد ما عنصر يختفي اقطع لايراته. واللي بيلخبطك وانت شغال بيلخبط المشاهد أكتر: خفّف الشاشة زي ما بتخفّف التايملاين.
- لوحة ألوان الستايل صورة صغيرة في ركن الكومب للقطارة، وتتقفل قبل الرندر.
