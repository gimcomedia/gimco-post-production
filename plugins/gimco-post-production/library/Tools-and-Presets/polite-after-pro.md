- **المتطلبات:** الإكستنشن مرخّص
- **البديل Native:** Whisper للتفريغ، Lumetri للجريد، ماسكات يدوي

## Polite After Pro (صاحب الإكستنشن) — v9.1.2

إكستنشن CEP لافتر ايفكت 2019–2026 على Windows 10/11. مكتبة Presets + أدوات مونتاج (Auto Edit، Subtitles، Silence Remover، Colour Grading، iPhone Colour، Mask، Keyframes، Polygon، Markers). المصدر: الدليل العربي المبني على دليل صاحب الإكستنشن المرجعي + تجربة عبدالله العملية. أسماء الأزرار تفضل إنجليزي زي ما هي في البانل.

## إمتى نستخدمها في شغل عبدالله
- ريل دكتور خام وعايز نسخة أولى بسرعة جوه افتر: Auto Edit (سكوت → زوم → ترانزيشن → كابشن → لون → مزيكا مع Ducking) وبعدين نكمّل بإيدنا بأسلوب abdallah.
- تفريغ كابشن عربي: Subtitles جوه البانل شغال مع العربي عادي (مجرّب عند عبدالله)، فهو خيار أساسي للكابشن بجانب Whisper المحلي. الدليل الأصلي بيوصف الموديلات بالمرجعي، لكن التجربة العملية أثبتت إن العربي بيتفرّغ كويس.
- قص الوقفات بس: Silence Remover.
- فيديو آيفون HDR باهت/محروق في افتر أو بريمير: iPhone Colour قبل أي جريد.
- جريد سريع غير مدمّر + تصدير LUT للبريمير: Colour Grading.
- تحريك واجهة تطبيق/موقع (حجز، واتساب، صفحة العيادة) من سكرين شوت: Mask (Parts → masks → Layers + animation + Cursor).
- Easing دقيق، أشكال، وماركرز In/Out للـ Text Presets: Keyframes / Polygon / Markers.
- تخزين أي حاجة بنكررها (Preset، Comp، Expression، فونت، منحنى إيزينج) في مكتبة واحدة.

## 1) التثبيت والتفعيل
- ملف .zxp يتثبت بـ ZXP Installer أو Anastasiy's Extension Manager (ممنوع تغيير الامتداد لـ zip). اقفل افتر بالكامل وافتحه → Window > Extensions > Polite After Pro.
- الترخيص: كود + إيميل الشراء → Activate → تأكيد أخضر وعدد الأيام. محتاج إنترنت.
- أول تشغيل لبعض الأدوات بيحمّل ملفات مساعدة (FFmpeg، Speech Engine) مرة واحدة؛ لو وقف فيه تنزيل يدوي جوه الأداة.

## 2) الواجهة
شريط علوي:
- Save: قائمة الحفظ (تحت).
- Search: بيدوّر بس في الفولدرات اللي اتفتحت مرة قبل كده.
- In / Out / Both: نوع تطبيق أنيميشن النص (دخول، خروج، الاتنين).
- أيقونات الأدوات: Colour Grading، iPhone Colour، Auto Edit (العصاية الدهبي)، Silence Remover، Mask، Keyframes، Polygon، Markers، Subtitles.
المكتبة الجانبية: فولدرات + أزرار فولدر جديد / حذف / إعادة تسمية / Import / Export.
مساحة العناصر: كليك على العنصر = يتضاف للكومب. Hover = Preview متحرك أو صوت. Pin يثبّت الفولدر.
الشريط السفلي (بالترتيب): Reload Folders، License (المفتاح)، Packages (الصندوق)، Add Base Folder، Settings (الترس) ودليل الاستخدام، سلايدر حجم الثمبنيلز، سلايدر صوت الـ Preview، رقم النسخة (مهم للدعم). لما البانل يضيق الأزرار بتبقى أيقونات بس.

## 3) قائمة Save (اختار فولدر → حدد اللاير/الكومب → Save → اسم → معاينة تلقائية)
- Save Codes: سكريبتات/أكواد.
- Save Project Path: نسخة من المشروع كله مع تجميع الملفات في فولدر.
- Save Layers: اللايرز بالإفكتس والأنيميشن.
- Save Composition: الكومب كامل بملفاته.
- Save Multiple Comps: أكتر من كومب.
- Save Marker: ماركرز الكومب.
- Save Font: فونت التكست لاير المحدد.
- Save Masks: ماسكات اللاير.
- Save KF-Interpolation: منحنى الإيزينج بين الكيفريمز.
- Save Expression: إكسبريشنز اللاير.
- Save Preset: إفكتس + أنيميشن كـ Preset.
في حفظ Project/Comp بينسخ الميديا المرتبطة عشان مايبقاش فيه Missing Files؛ اللي فشل بيظهر اسمه في الآخر.
تطبيق Preset/Effect: لازم تحدد اللاير الأول وبعدين تدوس على الـ Preset.

## 4) الباقات والترخيص
- Packages: Base Folder على درايف فيه مساحة (مش C لو مليان) → Download (التحميل بيكمّل من آخر نقطة) → الباقة تظهر في المكتبة. المقفول = مش في ترخيصك.
- حالة الترخيص: عدد أيام = المتبقي؛ برتقالي متحرك = 7 أيام أو أقل؛ أحمر + ! = غير مفعّل/منتهي؛ ∞ = دائم.

## 5) Settings
تبويب Library:
- Data Folder: موديلات الكلام والقوالب والملفات المؤقتة → درايف واسع، مش فولدر OneDrive.
- System Check: يختبر Speech Engine وFFmpeg → أول حاجة لو أداة مش شغالة.
- Clear Cache: يمسح الصوت/الرندر المؤقت والتحميلات الناقصة.
- Library View: Thumbnails، Labels، Numbers، Audio waveforms، Limit waveforms in big folders (200+ صوت).
- Saving Preview: No thumbnail / Still PNG / Live preview بمدة أقصاها (ثواني).
تبويب Appearance: ثيمات Cutline, Glass, Midnight, Aurora, Ocean, Emerald, Sunset, Gold, Mono (Auto Edit يفضل دهبي دايمًا)؛ Customize colours (Accent، Accent 2، Background + Reset)؛ Preview frame (Wide/Square/Tall/Original + Fit whole preview / Fill frame)؛ Roundness 0–180% لكل ثيم؛ Interface size. فيه كمان تبويبات Effects وAbout. أي تعديل بيتحفظ فورًا.

## 6) Auto Edit (افتح كومب → العصاية الدهبي، أي مرحلة ممكن تتعدّى أو ترجعلها)
1 Video: Use the selected layer أو Pick a video file (بيعمل كومب جديد).
2 Silences: قص الوقفات.
3 Zoom: Punch in على بعض الكلبات.
4 Transitions: بين القصات.
5 Subtitles: تفريغ (العربي شغال) + تعديل النص والتوقيت.
6 Caption style: Single / Multi / صاحب الإكستنشن.
7 Colour: Look من المكتبة.
8 Music: مزيكا بتنخفض تحت الصوت (Ducking). المؤثرات الصوتية ما بتعملش Ducking.
9 Done: مراجعة وتعديل أي مرحلة. فوق فيه تايم لاين مصغّر ترجّع منه أي جزء اتشال غلط.
لو الـ Ducking مش شغال وظهر No Speech Found → نفّذ مرحلة Subtitles الأول. مكتبات Shake/Transitions/Looks/Music فاضية في أول مرة → عرّف فولدر كل نوع: Shake بصيغة AEP/FFX، Transition فيديو، Look كـ FFX، Music ملفات صوت.

## 7) Subtitles (التفريغ العربي شغال عملي)
حدد لاير فيديو/صوت → Subtitles → اختار الموديل اللي بيدي أفضل نتيجة عربي → Create Subtitle → صحّح → To Timeline.
أزرار المحرر: Save، To Timeline، Open، Translate (Google / AI)، عدد كلمات السطر + Words، Split (إعادة تقسيم حسب توقيت الكلمات)، Punct. (شيل/رجّع الترقيم)، بحث، Close gaps، Merge، Sync، Delete، Undo/Redo، Auto play، Play on click، سرعة التشغيل.
Waveform: اسحب الطرف = طوّل/قصّر؛ اسحب البلوك = حرّك في الزمن؛ دبل كليك في فاضي = سطر جديد؛ دبل كليك على الطرف = يلزق على بداية/نهاية الكلام؛ مع ربط الحدود سحب الحد المشترك بيعدّل السطرين.
اختصارات: Space تشغيل/إيقاف، Enter تشغيل السطر، Shift+←/→ ثانية، Ctrl+←/→ فريم، Alt+←/→ تحريك السطور المحددة 50ms، Ctrl+H بحث واستبدال، Ctrl+S حفظ، Ctrl+عجلة = زوم التايم لاين.
فيه ذاكرة تصحيح للأخطاء المتكررة بتفضل بعد التحديث (مفيدة لأسماء الدكاترة والمصطلحات الطبية). أداة تنسيق الحروف/الرسمي-العامي معمولة للمرجعي، فما نعتمدش عليها للعربي. على جهاز متوسط اقفل معاينة الصورة جوه المحرر.

## 8) Silence Remover
حدد لاير واحدة (فيديو/صوت/بريكومب فيه صوت) → Use selected layer → الأحمر = مقترح للحذف، كليك على وقفة يحتفظ بيها (Wheel سكرول، Ctrl+Wheel زوم).
- Silence threshold (افتراضي -38 dB؛ Auto threshold يختار مستوى فوق ضوضاء الأوضة شوية).
- Minimum silence (500ms): أقصر سكوت يتقص.
- Padding before/after (80ms): أمان لأول وآخر الحروف.
- Shortest clip to keep (200ms): يمنع القصاصات الصغيرة.
طرق التنفيذ: Cut & Close Gaps (يقص ويلم)، Cut & Keep Gaps (يقطع ويحافظ على التوقيت)، Markers Only.
لاير عليها Time Stretch/Remap → رجّعها 100% وعطّل الريماب الأول. لو فيه مزيكا تحت الكلام ومش لاقي سكوت → ارفع الـ threshold أو قلّل Minimum silence. لو عايز يمسح كله → نزّل الـ threshold ناحية Noise Floor.

## 9) Colour Grading (غير مدمّر)
اختار لاير → Pick footage → بيكتشف Log/HDR/iPhone/عادي → Analyze & Correct (Exposure، White Balance، Black/White points) → تعديل → Apply grade. Amount سلايدر للقوة.
تبويبات: Primary (Exposure، Contrast، Pivot، Highlights، Shadows، Whites، Blacks، Temperature، Tint، Saturation، Vibrance، Hue rotate، حماية Skin tones)، Wheels (Lift/Gamma/Gain)، Secondary (مجموعات: بشرة، سما، نباتات، أسفلت)، Looks. خيارات سينمائية: Film Contrast، Split Saturation، Filmic Roll-off.
Presets: Natural، Teal & Orange، Warm Skin، Moody، Vivid، Dramatic.
Space تشغيل، Phone / Web معاينة زي الموبايل، Save preset، Export LUT (65-point للبريمير وغيره)، Reset، Restore للأصل.
لريلز المتكلم: ابدأ بـ Analyze & Correct + Warm Skin أو Natural مع حماية البشرة، وصدّر LUT لو المونتاج هيكمل في بريمير. **الجريد النهائي في بريمير (Lumetri)؛ Polite يطلّع LUT بس** (حتى لو Auto Edit عمل لون ومزيكا، الجريد والمزيكا النهائيين في بريمير).

## 10) iPhone Colour
Selected / This comp / Whole project → Find videos → HDR بعلامة دهبي → Before/After → اختار الجودة → Fix colour (بيعمل نسخة ويبدّلها، الأصل ماتلمسش).
الجودة: Phone-like (حجم قريب وشكل الموبايل)، 10-bit (أكبر ومناسب للمونتاج)، Full HD (أخف وأسرع). سلايدر فتح/تغميق، Restore Original. شغالة كمان مع Premiere Pro.

## 11) Mask (3 مراحل)
1 Edit mask: Select Mask → Reverse، Flip H، Flip V، Rotate، Scale، Round corners، Expand/contract، Optimize points.
2 Parts → masks (البانل بيفتح عليها افتراضيًا): اختار لاير السكرين شوت → Find parts. Method: Shapes & edges / Colours (old). Sensitivity، Join distance، Padding، Smallest part، Round corners. Parts: Boxes (كل زرار/كارت جزء) / Detailed (يفتح الكروت لحقولها) / Box + inside (البوكس + أيقونته ونصه، لحد 3 ماسكات). خيارات: Corners like each part، Backgrounds too، Replace the masks of the layer. عدّل المستطيلات في المعاينة → Build masks.
3 Layers + animation: كل ماسك يبقى لاير ويدخل ورا التاني. تبويبات: Motion (Bounce، Pop، Zoom، Rotate، Fade، أو اتجاه؛ منفصل للخلفية/النص/الأيقونات؛ + Save Mine)، Timing (الفرق بين الدخولات والترتيب، مثلًا 3f offset)، Groups، Exit، Sound (Pop متزامن)، Cursor، Output (Controller Null، Motion Blur، 3D، Scroll للصفحة).
زرارين: Build layers + animation (يبني من الماسكات) / Animate the selected layers (يطبّق على لايرز موجودة).
Cursor on the selected layers: حدد اللايرز → حط الـ CTI عند البداية → Click order (As selected / Top → bottom / Left → right) → Entry time، Wait on each، Exit time بالفريم (أكبر = أبطأ) → Build the cursor.
تخصيص الكيرسر: شكل Mac/Windows/Hand/Pen/Dot/Circle بحجم ولون؛ مسار (جهة الدخول، الانحناء، دوران تلقائي، سلاسة)؛ رد فعل Press/Jelly/Pop/Shake/Tap أو بدون؛ Click Ripple وصوت.
بعد البناء: حرّك Nulls اسمها Click لتغيير مكان الضغطة، وكيفريمز Move Progress على لاير PA Cursor لتغيير التوقيت.

## 12) Keyframes / Polygon / Markers
- Keyframes: حدد 2+ كيفريم → حرّك الهاندلز في Speed Graph أو اكتب In X/Y وOut X/Y في Point Inspector → Set Interpolation. Ctrl دائري، Alt خطي، Shift سناب، Ctrl+Alt متناظر، العجلة زوم، الزرار الأوسط Pan، Reset/Fit/Center.
- Polygon: Rectangle، Triangle، Trapezoid، Parallelogram، Polygon → Length/Width، الزوايا، الأضلاع، Roundness (سكرول أو أسهم؛ Shift ×10، Alt ×0.1) → Create. المقاسات بتتحدث لايف على اللاير بعد الإنشاء. لازم كومب مفتوح.
- Markers: Create/Delete In، Both، Out على اللايرز المحددة؛ In/Out distance (%)؛ Set In/Out بتايم كود أو Set In/Out to CTI؛ Move markers بالفريم + Marker gap + Fixed gap؛ Copy/Paste Marker بين اللايرز. الـ Text Presets بتعتمد على ماركرز In/Out لتوقيت الظهور والاختفاء.

## 13) الدعم
أيقونة الرسائل في طرف البانل (مجتمع + Dark Mode). مع أي بلاغ: رقم النسخة، نسخة افتر وويندوز، اسم الأداة، نص الخطأ أو سكرين. تيليجرام t.me/صاحب الإكستنشن_support، الموقع صاحب الإكستنشن.ir.

## 14) حل المشاكل
أول 6: إنترنت + سماح AfterFX.exe في Windows Firewall؛ جرّب بدون VPN/Proxy؛ شوف لو الأنتي فيرس عزل ملفات؛ نسخة حديثة من مصدر موثوق؛ أسماء الملفات والمسارات إنجليزي؛ JavaScript في File > Project Settings > Expressions لكل مشروع. ما نقفلش الحماية بالكامل، نعمل استثناء محدد.
ترخيص: واقف على License Checking → اتأكد من النت واقفل/افتح البانل. could not be activated → الكود من غير مسافات، إيميل الشراء، مش كود X Pro. التفعيلات خلصت/غيرت ويندوز → الدعم يحرر الجهاز. 0 days → جدّد من My Services. باقة مقفولة والترخيص شغال → نفس الإيميل، أو الدعم.
تثبيت/بانل: مش ظاهر → اقفل افتر من Task Manager، افتر 2019+، شوف Extensions (Legacy). أبيض/فاضي → الأنتي فيرس وأعد التثبيت. بيهنّج → حدّث افتر، وقف إضافات CEP قديمة، Reset Preferences (Ctrl+Alt+Shift عند الفتح). اختفى → Window > Workspace > Reset to Saved Layout. العربي مفكك → Preferences > Type > Text Engine > South Asian and Middle Eastern وأعد التشغيل. مسار الإضافات: C:\Program Files (x86)\Common Files\Adobe\CEP\extensions.
مكتبة: Expression Error → JavaScript + Allow Scripts to Write Files and Access Network. Missing Effects → ثبّت البلجنز المطلوبة (Deep Glow 2، Shadow Studio 3). Extract فشل → مساحة + امسح التحميل الجزئي وأعد. باقة مش ظاهرة → Reload Folders + نفس مسار Packages. البحث مش لاقي → افتح الفولدر مرة. افتر بيقفل مع Preset تقيل → Purge All Memory & Disk Cache وAdjustment Layer. بطء → Limit waveforms، اقفل Live preview، Clear Cache.
