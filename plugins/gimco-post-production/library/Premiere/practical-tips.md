- **المكان:** نصي

- **البديل Native:** ماسك يدوي
- **الفهرس:** [INDEX](../INDEX.md)

## مونتاج بريمير (اتعلمناه بالتجربة)
- **مقاس السيكونس:** اتأكد منه الأول. ريل سابق كان 720×1280 حتى لو بيتصدّر 1080×1920، والـ Position 360/640 بيكشفه.
- **اللصق:** Paste بيروح لرقم التراك الأصلي بتاع الكليب، مش للتراك المتعلّم. عشان تحط كليبات على V6، ابنيها في XML على تراك 6 (وسيب تراكات 1–5 فاضية)، وبعدين Import > افتح السيكونس > Ctrl+A > Ctrl+C. ارجع للسيكونس، حط البلاي هيد على أول كليب، واعمل Ctrl+V، وهتعمل Overwrite مكان القديم.
- **المسح:** زرار Delete ممكن ما يشتغلش؛ استخدم Edit > Clear.
- **الوقت:** خانة التايم كود فوق التايم لاين، اكتب «0202» يعني 2 ثانية و2 فريم.
- **التعديل الجماعي:** لوحة Properties بتعدّل Scale لكذا كليب مرة واحدة.
- **ماسك الدكتورة (Object Mask):**
  - لو حتة صغيرة زي المايك أو الإيد ظهرت فيها الخلفية الجديدة: اختار الـ Object Mask، وShift+click عليها بأداة Object Mask، وبعدين "Track selected mask forward".
  - لو التراكينج فقدها، زوّد Rectangle Mask ثابت (اضغط مطوّل على أداة Object Mask واختار Rectangle Mask Tool) حوالين المكان ده في نفس الـ Opacity، بشرط إن المنطقة ما فيهاش حيطة (هدوم أو مكتب بس).
- **التصدير:** H.264 1080×1920 في Documents باسم claude_<المشروع>_reviewN.mp4. بعدها اعمل كونتاكت شيت وراجع.
