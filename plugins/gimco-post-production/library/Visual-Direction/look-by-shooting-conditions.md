## 9) اختيار اللوك العام حسب ظروف التصوير
الاختيار بين لوك المجلة والـ UI الغامق والسينمائي لريل متكلم: [style-systems](style-systems.md) («اختيار اللوك لريل متكلم»). الجدول ده حسب الخامة والست.

> **حارس طبي:** في الشغل الطبي قواعد [medical](../Specialized/medical.md) هي اللي تكسب: Teal مطفي مش نيون (مفيش هولوجرام أزرق منوّر)، وأي «قبل/بعد» **بموافقة مكتوبة ومن غير ادّعاء نتيجة**، والبي-رول مش دليل على نتيجة.

| المتاح | اللوك |
|---|---|
| خلفية ساده بلون البراند والمتكلم بالطول | تغيير البيئة ورا المتكلم، أو كينتك تايب + كت-أوت (ممكن تمزجهم) |
| ست حقيقي فيه أثاث وبروبس | جلاس + نيون بلون البراند + Defocus transitions + Layout البراند للأقسام |
| ستوديو غامق Low-key | كابشن كبسولة + عالم UI فاتح بيتقطع معاه |
| ست طبي غامق (أوضة عمليات، كشاف فوق الراس) | جريد أزرق بارد + جرافيكس هولوجرام أزرق منوّر (سيلويتات، أيقونات جلاس، حلقة مدار) + كابشن أبيض/أزرق، والختام بلون البراند الدافي |
| ست عيادة غامق + محتوى عرض/أوفر | عالمين: متكلم غامق بنص Teal هادي منوّر + كروت Mint/أبيض كأنها تطبيق، وكروت فصول بأرقام، وبي-رول مولّد للمشهد السلبي، وجلاس للبادجات والهدايا والندرة |
| موبايل / كاميرا 1080 واحدة | زوم هادي بدل punch-in، وجلاس وكابشن، وخلّي الجرافيك هو اللي يشيل التنويع |
| ست غامق ونور ملوّن قوي ورا المتكلم (أنابيب RGB أو LED)، كادر متوسط متسنتر وتحته غامق | كابشن تقيل بكلمة خاصة بلون النور + هوك تايتل بأيقونة أو كارت UI + كروت وموكابات تطبيقات جلاس غامق على الصدر و full-screen. الأكسنت يمشي مع لون النور في كل قسم. [recipe-dark-ui-talking-head](../After-Effects/recipe-dark-ui-talking-head.md) |
