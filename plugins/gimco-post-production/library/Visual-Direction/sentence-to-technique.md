## 1) من الجملة للتكنيك (قلب الدليل)
> **حارس طبي:** في الشغل الطبي قواعد [medical](../Specialized/medical.md) هي اللي تكسب: Teal مطفي مش نيون (مفيش هولوجرام أزرق منوّر)، وأي «قبل/بعد» **بموافقة مكتوبة ومن غير ادّعاء نتيجة**، والبي-رول مش دليل على نتيجة.

| الجملة بتعمل إيه | التكنيك | التنفيذ |
|---|---|---|
| هوك / سؤال صادم | تغيير عالم أو حجم في أول 1–3s: خلفية تتبدل ورا المتكلم، أو عناصر بتطير ناحية الكاميرا، أو كلمة ضخمة بتملا نص الكادر، أو **كلمة ضخمة ورا المتكلم** (الراس والكتاف قدامها) | كي/روتو + خلفية مولّدة، أو كت-أوت بـ Motion Blur، أو Text Animator Scale، أو Roto Brush + النص بين نسختين من الفيديو |
| أماكن / «تخيّل نفسك في...» / مرونة الخدمة | الخلفية تتبدل ورا المتكلم على كل كلمة مكان، وفي الآخر كشف الحاجة الخام (الأخضر، الست الحقيقي) كإثبات | كروما + خلفيات مولّدة بنفس زاوية الكاميرا، كت حاد على الكلمة، الكابشن ثابت. الوصفة في recipe-glass-ui-over-speaker |
| أنواع / خدمات / استخدامات متعددة | عالم مختلف لكل بند ورا نفس المتكلم، والكلمة جوه دايرة أو كبسولة جلاس | نفس طريقة تبديل العوالم، بند لكل 1–2 ثانية |
| رقم من خانتين (4 في 1، 2×1، 24/7) | الخانة الأولى ضخمة **ورا** المتكلم (Fill بلون البراند + Deep Glow Radius ≈260، Exposure 0.01) والتانية **قدامه** بـ Gradient Ramp Linear أبيض فوق ← غامق تحت (يدوب في الحجر/الكرسي). خط Black تقيل، والخانتين مش على نفس الخط (واحدة فوق شمال، والتانية تحت يمين). يدخلوا بالـ Color Echo Wipe، وتحتهم Pill جلاس فيها الجملة | Roto/Object Selection + Freeze، والمتكلم المعزول بين النسختين (caption-and-reel-recipes «ريفيل بمسح مايل») |
| "إيه أهم حاجة عندك؟" / اختيار بين أولويات | كبسولات اختيار بيض بأيقونة ودايرة راديو بتتعلّم واحدة واحدة | Shape Rounded Rect + Ellipse، Scale بارتداد. recipe-offer-two-worlds |
| التزام بالمواعيد / سرعة التسليم | ويدجت كاليندر جلاس والتاريخ بيعدّ والأيام بتلف | Slider + إكسبريشن للرقم، وصف الأيام Position بيزحلق. recipe-offer-two-worlds |
| فوضى / تشتت / مشكلة متكررة (أسعار، ورق، موردين) | عالم البراند وورق بيطير ويتقلب، وبعده كارت مستند مجرد بيطلع | لايرز 3D بـ Rotation عشوائي أو Particle World بسبرايت ورقة |
| كلمة أو سؤال عايز تركّز عليه | الكلمة متعلّمة كأنها Text Selection في الموبايل وفوقها منيو Copy / Look Up / Share | Rect أزرق شفاف ورا الكلمة + كارت منيو صغير بيطلع بارتداد |
| هوك بيوعد بنتيجة أو بيتكلم عن مشكلة | جرافيك قبل/بعد تحت نص S+P: الحالة اللي مش عايزها، أو النتيجة، أو الاتنين | كت-أوت على النص التحتاني من جسم المتكلم، والنص 2–6 كلمات فيه كلمة مؤثرة ملوّنة |
| هوك فيه اسم حاجة أشهر من المتكلم | Borrowed Interest: كت-أوت الحاجة/الشخصية تحت النص | Position من تحت + Inertia. في الإعلان: حاجة عامة مش براند تاني |
| هوك «هعلمك X» / «3 حاجات» | معاينة القيمة: الإطار نفسه مقفول (3 مربعات ✗ أو «؟») أو الدياجرام اللي هيتشرح | Stagger 4–6 فريم، والإطار ده هو اللي هيرجع كهيكل الفيديو |
| هوك فكرة مجرّدة («النجاح مش حظ») | صورة رمزية واحدة بس، مش كولاج | أيقونة/كت-أوت واحد في النص + Glow لحظة الدخول |
| المتكلم ماسك أو بيعمل حاجة في أول لقطة | هوك ديناميك: سيب اللقطة، النص بس | S+P بعيد عن الحاجة الممسوكة، من غير أي جرافيك فوقها |
| «عندي X أسئلة / خطوات» (هيكل ممتد) | الإطار كامل ← حالة نشطة لكل بند (المنوّر كبير، والباقي باهت) ← ريكاب قبل الـ CTA | كومب إطار واحد + Slider «Active» |
| مقارنة مستويين أو شخصين | شاشة مقسومة مايلة، والجانب اللي مش بيتكلم غامق ومنزوع اللون | Hue/Saturation −100 + Exposure −1 على الجانب الباهت، وبيتبادلوا مع الكلام |
| «لو كذا يبقى كذا» | شجرة قرار والمسار الحالي منوّر | Trim Paths للأسهم + Opacity للفروع الباهتة |
| حاجة بتحصل على منصة (مكالمة، دفع، رسالة، بحث) | نسخة طبق الأصل من الواجهة، وأحيانًا المتكلم نفسه جواها (إطار مكالمة فيديو) | Shape Layers من سكرينشوت، ومن غير كيبورد، وجوه المنطقة الآمنة |
| خطوات على موقع أو تطبيق | Walkthrough: المتكلم فوق والشاشة تحت، وضغطة + هايلايت لكل خطوة اتقالت | recipe-click-effects، والخطوات بنفس الترتيب ومن غير نط |
| جملة جانبية قصيرة جوه مشهد شغال | تمثيل صغير فوق التمثيل الحالي (أيقونة أو إشعار) بدل مشهد جديد | Overshoot صغير في ركن المشهد، ويخرج قبل الكت |
| «اكتب كلمة X وأبعتلك» | معاينة الهدية الأول ← مربع الكومنت والكلمة بتتكتب | Typewriter في مربع كومنت طبق الأصل |
| نسبة صغيرة من الناس / «دول بس اللي...» / 1 من كل 10 | شبكة أيقونات أشخاص outline (مثلًا 10×10) جوه براكت زوايا، وعنوان صغير فوق. المجموعة المقصودة بتتملى أبيض/أكسنت والباقي يفضل outline باهت. نقطة تركيز واحدة | Repeater أو CC RepeTile لشبكة الأيقونات، ونسخة Fill للمجموعة بتدخل Stagger 2–3 فريم. layout-principles (التركيز) |
| رقم أو نسبة أو إحصائية | عداد ضخم ورا المتكلم أو جنبه، أو كارت جلاس فيه عداد، أو شارت بيترسم | Slider + إكسبريشن، و مكتبة vahid_graph (Counter_Box، Percentage_Box، Progress_Chart) |
| مكونات / تقسيم / ماكروز | صف أيقونات line تحت العنصر، أو كارت بيتفتح لفروع | Trim Paths للأيقونات، وكروت متربّطة بخطوط |
| ليستة (أعراض، خطوات، مميزات) | صفوف جلاس بتتراكم واحد ورا التاني جنب المتكلم، أو كبسولة لكل بند | Liquid_Text_Box، و Text_box_2، و stagger 6–10 فريم |
| سبب أو خطوة مرقمة | بادج رقم + عنوان | Box_in، و Step_Title_Badge |
| حاجة ملموسة (دواء، أكل، جهاز) | الصورة كت-أوت قدام جسم المتكلم كأنه ماسكها، أو كاروسيل بيعدّي قدامه | Position من برا الكادر + Inertia، وظل خفيف تحت |
| فكرة "المشكلة الحقيقية" / قلب سؤال | كارت جلاس مايل 3D فيه الجملة، وأيقونة 3D (؟ أو !) راكبة على ركنه بلون الأكسنت | كارت 3D Layer بـ Rotation Y/X خفيف + أيقونة بـ Overshoot متأخرة 4–6 فريم |
| أمثلة / ناس / نتايج | كروت صور مصغرة أو أفاتارز بتطلع وتلف جنب الراس | 3–4 كروت stagger، Rotation مختلف لكل واحد، وطفو خفيف |
| "إنت واحد من كتير" / منافسة / الاختيار | مشهد full-screen غامق: صف أشخاص هولوجرام فوق منصات منوّرة، وواحد بس منوّر أقوى وفوقه سهم. وللسؤال "طب هيختاروك إزاي؟" الكاميرا ترجع لورا والصف يبقى زحمة | سيلويت متكرر بلون الباليتة + Glow، والمختار Opacity و Glow أعلى. الوصفة في مكتبة After-Effects |
| خدمات أو مميزات متعددة (3–5 بنود قصيرة) | حلقة مدار متقطعة حوالين صدر المتكلم عليها أيقونات جلاس 3D بتلف، والأيقونة بتاعة البند الحالي بتكبر مع الكلمة. في الآخر الحلقة بتكبر وتطير بره الكادر | Null بيلف في النص والأيقونات Parent ليه ومعدولة. الوصفة في مكتبة After-Effects |

| صح أو غلط / خرافة أو حقيقة | لون حالة لحظي (أخضر/أحمر)، أو ختم، أو علامة صح، أو استطلاع بزرارين | Wave_Click_Green/Red، و Liquid_Poll_Box، و Danger_Box_v2 |

| خدمة رقمية / تطبيق / حجز | عالم UI فاتح منفصل (شات، أو زرار بيتداس، أو كارت، أو سيرش بيتكتب) يتقطّع مع المتكلم | كومب UI + Typewriter + Secondary_Click |
