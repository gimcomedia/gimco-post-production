# مشهد 3D بـ UI

- **الإحساس:** عالم كامل بيتلف فيه.
- **اللي بيبان:** أوضة أو مكتب 3D، كروت بتنط، كاميرا بتتحرك في عالم واحد.
- **يناسب:** SaaS، براند تقني. **ما يناسبش:** ميعاد ضيق.
- **المفاتيح الافتراضية** (إيقاع · نص · انتقالات · كثافة الموشن · لون · صوت · جرأة · خامة): متوازن · تقيل واضح · حركة كاميرا · موشن كامل · باليتة البراند · ساوند ديزاين غني · تجريبي · جلاس وعمق.
- **المراجع:** [recipe-dynamic-3d-ui-scene](../../After-Effects/recipe-dynamic-3d-ui-scene.md) · [recipe-app-ui-scene-3d-canvas](../../After-Effects/recipe-app-ui-scene-3d-canvas.md).

## البرومبت
حط ده مكان `[الستايل]` في [البرومبت الأم](../styles.md) (القسم 3)، واملا اللي بين `[ ]`:

```text
الستايل: مشهد 3D بـ UI.
- عالم واحد ([مكتب/أوضة/كانفس]) والكاميرا بتتنقل جواه بدل القطع.
- كل نقطة = كارت UI بيطلع بباونس في مكانه في العالم.
- العربي كلمة كلمة بلاير نص لكل كلمة أو سطر.
```

## البناء
- افتح recipe-dynamic-3d-ui-scene.
- كانفس التطبيق من recipe-app-ui-scene-3d-canvas.

## تشييك قبل التسليم
- الكاميرا ناعمة.
- النص مقروء في كل زاوية.
- قواعد البيت: باونس البيت على كل عنصر بيدخل، خط SemiBold وأتقل، العربي كلمة كلمة، كل عنصر على فريم كلمته أو بعده بـ 0–3 فريم.
