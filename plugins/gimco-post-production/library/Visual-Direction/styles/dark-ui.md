# ست غامق + UI

- **الإحساس:** تقني وفخم ومنوّر.
- **اللي بيبان:** متكلم على ست غامق بنور ملوّن، كابشن أبيض تقيل وكلمة خاصة بلمعة وجلو، هوك تايتل بأيقونة أو كارت UI، كروت وموكابات تطبيقات.
- **يناسب:** شرح أداة أو تطبيق، أرقام ونتايج. **ما يناسبش:** ست فاتح، موضوع حساس.
- **المفاتيح الافتراضية** (إيقاع · نص · انتقالات · كثافة الموشن · لون · صوت · جرأة · خامة): ديناميك · تقيل واضح · كت نضيف + عيلة واحدة · مشهد مصمم لكل فكرة · غامق · SFX خفيف على التغييرات · متوسط · جلاس وعمق.
- **المراجع:** [recipe-dark-ui-talking-head](../../After-Effects/recipe-dark-ui-talking-head.md) · [recipe-selector-wheel-phone-cards](../../After-Effects/recipe-selector-wheel-phone-cards.md).

## البرومبت
حط ده مكان `[الستايل]` في [البرومبت الأم](../styles.md) (القسم 3)، واملا اللي بين `[ ]`:

```text
الستايل: ست غامق + UI.
- الهوك: تايتل تقيل بأيقونة [التطبيق/الموضوع] أو كارت UI بيطلع على كلمة الهوك.
- الكابشن أبيض تقيل، وكلمة واحدة «خاصة» في الجملة بلمعة (Light Sweep) وجلو أكسنت بـ Deep Glow 2.
- كل أداة أو رقم = كارت أو موكاب موبايل جنب المتكلم، بيدخل بباونس البيت ويخرج قبل اللي بعده.
- اللون: الغامق من الست، والأكسنت [لون النور اللي ورا المتكلم].
```

## البناء
- افتح الأقسام اللي محتاجها بس: 4 (سيستم النص)، 5 (الهوك)، 6 (الكروت).
- الأيقونات والتايتلز ببريستات الحركة الجاهزة (القسم 10).
- كومب لكل قسم وبيرجع بريمير Dynamic Link.

## تشييك قبل التسليم
- الجلو تلات درجات (همس/أكسنت/قمة واحدة).
- مفيش كارت فوق الوش.
- قواعد البيت: باونس البيت على كل عنصر بيدخل، خط SemiBold وأتقل، العربي كلمة كلمة، كل عنصر على فريم كلمته أو بعده بـ 0–3 فريم.
