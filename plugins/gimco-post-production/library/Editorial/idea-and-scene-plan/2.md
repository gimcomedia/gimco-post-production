## 2. Write the scene plan (EDITORIAL_PLAN.md) before touching the timeline

One row per important beat:

| Field | Decision |
| --- | --- |
| Phrase / message | Source words + timecode, or reviewed authored copy |
| Viewer takeaway | One concrete idea |
| Visual action | Initial state -> action -> resolved state; which object stays continuous |
| Timing | Cue, entrance, demonstration, readable hold, exit |
| Layout | Presenter (talk) / in-screen / full-screen takeover and why; energy: hard or calm |
| Assets | Exact named file or generated illustration + source note |
| Implementation | Premiere edit (cut, B-roll, zoom) or AE comp name |
| Text & sound | Literal subtitle vs explanatory label; action-linked sound or silence |
| Review concern | The hardest moment to understand or keep readable |

Show the editor a short recommendation and one representative passage before building everything. Keep approved direction; ask again only for a new consequential choice.
