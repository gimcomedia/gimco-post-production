## 2. اكتب خطة المشاهد (EDITORIAL_PLAN.md) قبل ما تلمس التايملاين

صف لكل جملة مهمة:

| الخانة | القرار |
| --- | --- |
| الجملة / الرسالة | الكلام الأصلي + التايم كود، أو النص المكتوب بعد مراجعته |
| المشاهد هيطلع بإيه | فكرة واحدة واضحة |
| الحركة البصرية | الحالة الأولى ← الحركة ← الحالة اللي بتقفل، وأنهي حاجة بتفضل مستمرة |
| التوقيت | الإشارة، الدخول، العرض، الثبات اللي يتقري، الخروج |
| التكوين | وش المتكلم / جوه الكادر / الشاشة كلها وليه، والطاقة: تقيل ولا هادي |
| الخامات | اسم الملف بالظبط أو الرسمة المولّدة + ملاحظة بمصدرها |
| التنفيذ | مونتاج بريمير (كت، بي-رول، زوم) أو اسم كومب الافتر |
| النص والصوت | كابشن حرفي ولا ليبل بيشرح، وصوت مربوط بالحركة ولا سكوت |
| نقطة المراجعة | أصعب لحظة تتفهم أو تفضل مقرية |

اعرض على المونتير ترشيح قصير ومقطع واحد يمثل الشغل قبل ما تبني كله. الاتجاه اللي اتوافق عليه يفضل، ومتسألش تاني غير على اختيار جديد ليه وزن.
