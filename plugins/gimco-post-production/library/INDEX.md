# مكتبة المراجع — الموجّه

الملف ده صغير عن قصد: اقراه كله، وما تفتحش غيره إلا اللي محتاجه.

## إزاي تدوّر

| عايز إيه | افتح |
|---|---|
| أول خطوة في أي شغل كامل الستايل بتاعه مش متحدد | [كتالوج الستايلات](Visual-Direction/styles.md) (36 ستايل ببرومبتها، والكارت يتفتح بعد الاختيار بس) + [direction-menu](Visual-Direction/direction-menu.md) + [قواعد البيت](Visual-Direction/style-systems.md) |
| نوع الطلب ← الوصفة والأقسام | الجدول تحت «ابدأ هنا» |
| احتياج محدد («نص ورا شخص»، «كارت يتمدد مع العربي»…) | [NEEDS](NEEDS.md): **دوّر فيه بكلمة، ما تقراهوش كله** |
| ملف معين أو قسم من المكتبة | [FILES](FILES.md) |
| اسم كورس أو باك أو صاحب ريفرنس | [SOURCES](SOURCES.md) · [LICENSES](LICENSES.md) |
| مكان ملف على الجهاز | [LOCATIONS](Tools-and-Presets/LOCATIONS.md) |

**الوصفات الكبيرة متقسمة لأجزاء:** ملف الوصفة نفسه بقى خريطة أقسام صغيرة، وكل قسم في ملف لوحده جوه فولدر باسم الوصفة. «القسم 10» يعني افتح الجزء رقم 10 من الخريطة بس.

مكتبة المراجع الثابتة لنظام السكيلات v2. السكيلات فيها القرار والخطوات، والمكتبة فيها التفاصيل والوصفات والقيم.
- كل ملف فيه في أوله: الاستخدام، المكان، المتطلبات، البديل Native.
- الأرقام (مدد، نسب، توقيت الهوك) أمثلة بتتكيّف مع الخامة والمنصة، مش قوانين.
- أسماء المصادر والباكات في [SOURCES](SOURCES.md) بس.
- أماكن الملفات الفعلية وحالة التحقق منها: [Tools-and-Presets/LOCATIONS](Tools-and-Presets/LOCATIONS.md).
