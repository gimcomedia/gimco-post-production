## رأس الخطة (سطر لكل بند)
- الهدف: الفيديو لازم يخلّي المشاهد يعمل/يفهم إيه؟
- الجمهور والمنصة والمقاس: (مثال: إنستجرام ريلز 9:16، مشاهد خليجي)
- الإحساس: (هادي فاخر / سريع وحماسي / دافي وإنساني...)
- الخامة: نوع التصوير، الكاميرات، الدقة، الصوت، اللوجو/صورة المنتج.
- الاتجاه الإبداعي في سطر: اللوك + عائلات الجرافيكس (2–3) + الأكسنت.
- الشغل المطلوب: مونتاج / موشن افتر / توليد / موجرت / صوت / لون / تسليم.
- الستايل: العيلة ومصدرها (براند العميل / مجاله)، والباليتة بأدوارها (60 / 30 / 10)، ونوع الخط الأساسي والخاص.

## تشييك سريع قبل البناء
- الهوك البصري بيوصل بدري (الرقم بيتكيّف مع المنصة والخامة).
- مفيش فترة طويلة من غير تغيير.
- النسب التقريبية بين المتكلم والـ full-screen والـ in-screen منطقية للمحتوى.
- كل جملة ليها فكرة واحدة أو مالهاش جرافيك.
- المجهود الأكبر رايح للـ Core، ولكل Core اتكتب 5 أفكار على الأقل واتختار منهم، ولكل Secondary 3 على الأقل.
- كل مشهد مصمم واقع على نقطة قيمة أو مفهوم جديد (مش بين نقطتين)، ومفيش عنصرين تقال ورا بعض، والفجوات الطويلة متغطية بحاجة أخف (مقطع نص، بي-رول). وريل 30–40 ثانية فيه 3–4 مشاهد مصممة بالكتير ([idea-and-scene-plan](../Editorial/idea-and-scene-plan.md): فين يتحط الأنيميشن).
- الستايل اتحدد قبل جمع الريفرنسات، وكل مشهد مصمم له ريفرنس بنفس نوع القيمة ونفس الستايل (أو مكتوب إنه من غير ريفرنس).
- في الفيديو الطويل: المقدمة واخدة أكتف وأحسن أنيميشن، والعدد بيقل مع الوقت ([structure-hook-safezone-pacing](../Editorial/structure-hook-safezone-pacing.md): «كثافة الأنيميشن على منحنى الاحتفاظ»).

## كارت خطة المشهد (لما المشهد بيتخطط من ريفرنسات)
كارت لكل مشهد مصمم، على اللوحة جنب جملته. المنهج في [idea-and-scene-plan](../Editorial/idea-and-scene-plan.md) («خطة مشهد من ريفرنسات»).

| البند | يتكتب إيه |
|---|---|
| الجملة + التايم كود | بالمنطوق، وخط تحت كلمات القيمة |
| المشاهد لازم يشوف | القيمة في 2–3 كلمات |
| الستايل | العيلة وسماتها اللي لازم تبان (خلفية، خامة، عدد الألوان) |
| الريفرنسات (5–8) | فريم + إيه اللي متاخد منه بالظبط (لاي آوت / مكوّن / معالجة) |
| الأصول | كل أصل ونوعه (صورة، Shape، نص، Solid) ومصدره المرخّص |
| الإفكتات | لكل أصل، أو «من غير» |
| الحركة | دخول كل أصل والخاصية (Position / Scale / Opacity / Trim Paths)، والكلمة اللي بيدخل عليها |
| ترتيب البناء | أصل 1 ← + أصل 2 ← … (ترتيب اللايرات في افتر) |
| الاسكتش | 9:16 أو 16:9 رمادي عليه حدود المنطقة الآمنة، والقيمة في الخانة الوسطى. في العربي التكوين معكوس (النص يمين) |
| تشييك | القيمة باينة؟ سمات الستايل موجودة؟ بطل واحد؟ الباليتة بأدوارها؟ |

## الستوري بورد البصري (شغل كامل أو لما العميل يوافق قبل التنفيذ)
- **التخطيط:** السكريبت كامل على جنب، وجنبه أقسام (Hook / Value / CTA، أو أقسام الإعلان). كل قسم فيه كروت 9:16. كل كارت فيه: جزء السكريبت فوق، وPreview للمشهد في النص (رسمة، أو أحسن: الجرافيك الحقيقي متصمم)، وسطر شرح تحت.
- **تقسيم المشاهد على حسب الفعل مش عدد الكلمات:** اسم أداة ممكن يبقى مشهد كلمتين، وشرح خطوات ممكن يبقى مشهد فقرة كاملة.
  - مشهد طويل زيادة = تمثيل قليل والفيديو يبقى ممل.
  - مشهد قصير زيادة = جرافيكس كتير ووقت أقل يفهم فيه المشاهد.
- **الترتيب:** ارسم الـ Core الأول، وبعدها الـ Secondary، وبعدها اقفل الفجوات بكابشن أو تمثيل خفيف. لازم كل كارت يبقى قريب من النهائي، عشان وقت التنفيذ ما يكونش فيه تفكير، تنفيذ وبس.
- **مود بورد الفيديو** على نفس اللوحة جنب الستوري بورد: الصور والواجهات والألوان والريفرنسات اللي هتحتاجها.
- **النسخ:** لو جت ملاحظات، اعمل v2 جنب v1 وما تمسحش. ساعات حاجة اتشالت ترجع.
- لو الجرافيكس اتصممت جوه الستوري بورد نفسه، بتتنقل لافتر على طول وتتحرك. وده بيغني عن خطوة «تجهيز الجرافيكس».
