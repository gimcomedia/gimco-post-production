# قالب موافقة التوليد (قبل صرف أي كريدت)

- **الاستخدام:** أي توليد صورة أو فيديو أو صوت بيصرف كريدتس.
- **المكان:** نصي
- **المتطلبات:** رصيد الحساب من الكونيكتور
- **البديل Native:** حل في افتر أو خامة موجودة
- **الفهرس:** [INDEX](../INDEX.md) · [model-choice-and-quality-ladder](../Generation/model-choice-and-quality-ladder.md)

---

اعرض الكارت ده واستنى الموافقة:

| البند | القيمة |
|---|---|
| المطلوب يتولّد | (مثال: 3 لقطات بي-رول 9:16، 5 ثواني) |
| ليه توليد مش افتر/خامة موجودة | سطر واحد |
| الموديل والإعدادات | الموديل، الدقة، المدة، المقاس |
| عدد المحاولات | (مثال: صورة الأول لكل لقطة، وبعد الموافقة تحريك) |
| التكلفة التقريبية | الكريدتس لكل عنصر × العدد = الإجمالي، والرصيد الحالي لو متاح |
| الخامات المرجعية | صورة المنتج / اللوجو / فريم Start و End |
| معيار القبول | إيه اللي يخلّي النتيجة تتقبل |

قاعدة: صورة الأول وبعدين تحريك. متكررش نداء توليد كإعادة محاولة من غير موافقة.
